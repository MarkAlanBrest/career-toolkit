# Future Enhancement Roadmap

## Report Expansion

- Late Submission Report.
- Ungraded Work Report.
- Discussion Participation Report.
- Feedback Not Viewed Report.
- Announcement Engagement Report.
- Student Contact History.
- Unanswered Messages Report.
- Administrative completion reports.

## Better Visuals

- Grade distribution histogram.
- Assignment completion heatmap.
- Missing work by week.
- Submission punctuality chart.
- Student activity sparkline.

## Workflow Features

- Saved report templates.
- Batch PDF export.
- Multi-course comparison.
- Course section filters.
- Searchable student case files.
- Print themes.

## Data Improvements

- Page views where instructor/account permissions allow.
- Discussion entry counts.
- Announcement/discussion engagement when API-visible.
- Gradebook history for audit-heavy environments.

## Optional Backend

Firebase support can add:

- Cross-device notes.
- Shared department templates.
- Role-based note access.
- Backup and export.

The backend must remain optional because many schools will be more comfortable with local-only storage for student notes.
